# Copilot Capstone Project

A Python-based agent project scaffold organized around a CREATE-style reasoning workflow, skills, memory, prompts, knowledge base, test suites, and output artifacts.

## Structure

- `agent/` contains agent runtime, skills, memory, and utilities.
- `knowledge_base/` contains reference knowledge and examples.
- `prompts/` contains system, skill, and output templates.
- `data/` contains datasets and profile metadata.
- `tests/` contains unit, integration, e2e, and mocks.
- `output_artifacts/` stores generated reports and phase outputs.
